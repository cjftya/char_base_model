# Reference images

Supply a folder or attach four images with base names `front`, `back`, `left`, and `right`. Supported extensions are PNG, JPG, and JPEG.

The skill copies each run's images into a timestamped workspace. See the [input specification](../skills/char-base-model/references/input-spec.md) for resolution, direction, and anchor conventions. This repository directory remains available for the legacy config example.
