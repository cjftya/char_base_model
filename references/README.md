# Input orthographic images

Place four real PNG references here (not generated by this repository):

- `front.png`: character seen from Blender Front view (camera on -Y)
- `back.png`: Blender Back view (camera on +Y)
- `left.png`: Blender Left view (camera on -X)
- `right.png`: Blender Right view (camera on +X)

Images should use the same character, pose (prefer simple A-pose), orthographic projection, and proportions. Use a visible neutral body silhouette without hair/clothes obscuring the base anatomy. This repository does not contain reference imagery yet.

In `config/reference_setup.json`, `head_y`, `foot_y`, and `center_x` are **fractional canvas coordinates** (0.0–1.0), with top-left origin. Set them to the **actual** crown, lowest sole, and body centerline of each PNG; defaults assume the character fills the entire image height. This calibration determines shared world height and Z=0 ground. Images containing margins require manual anchor adjustment.

"Left/right" uses Blender's viewport naming, not the character's anatomical left/right. All references are input data, not rendered outputs.
